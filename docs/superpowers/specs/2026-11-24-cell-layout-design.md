# 格內佈局：路網、元素、人車（2026-11-24）

## 參考

政策島的「和諧」來自：先有路再有東西；一條主幹道串起所有格；建築沿街、樹填畸零地、人在人行道；
大東西少、小東西多；標籤飄在上面不佔地。本專案採同一套原則，但路貼地不高架、外形是北海岸。

## 每格的骨架（已定）

```
環道：六角形環狀道路，半徑 0.70 R（車走）
人行道：環道內側一圈（人走）
門：環道六個邊中點；相鄰格的門用短路接起來 → 全島一個連通路網
格心：山 ＞ 建築級元素 ＞ 空廣場
街廓：環道內側、格心以外的區域，放元素
環道外側到格邊：樹、海灘、小碼頭
```

## 元素分配（已定）

- 建築級（school / library / hall / council-hall，1.5–2 單位）先放街廓，再放物件級（≈1 單位）。
- 同格同元素聚合成一組，`count` 控制大小或顆數；每格建築級 ≤ 3、物件級 ≤ 14 組，超過只累計數字。
- 位置語意：漁港、橋梁靠海側環道外；路口、公車亭、停車場貼環道；學校、圖書館、活動中心、市場在街廓內；
  修復工程靠格邊坡；活動、遊戲場在綠地。
- 淡水內陸四格照實留空（有環道、樹、山，沒有政績物件）——看起來是山區，不是沒做事。

## 橋（已定）

橋面是弧線：從一側環道的門起坡、過水面拱起、落到對岸的門；塔、拱、墩都沿弧線放。
端點從格心改到環道的門。

## 人車（保留，未做）

車只走環道 + 連接路 + 橋，閉路可一直繞。人只走人行道、斑馬線（crosswalk 元素）、格心小徑。
元素只能落在街廓多邊形裡，不能壓路——所以路網先於元素產生。

## 議會島

一格，中央議會大樓，環道照有，九種物件沿人行道內側排一圈。沒有橋；一條虛線航路 + 一艘小船接主島。

## 資料流

`data/cells.json`（每格貼文）＋ `temp/elements.json`（每篇的元素 id，另一 agent 產出）→ 放置演算法 → 場景。
