## 最相關的五個

- **妃妃鐵馬（#2）**
  - 唯一一個用真實 GPS 呈現政治人物每天位置的作品，GPS 資料來自宗教遶境平台 `gps.godroad.tw`。
  - 附加功能：37 區集章、LINE 和 IG 限動分享卡。三大報都有報導（2026-11-06）。
  - 缺的部分：2D 地圖，沒有政績、沒有回顧、沒有匯出影片。選舉結束就停止。
- **HEART（#1）**
  - 已經改版到 18 個主題、122 個細項，有「台北人的一天」播放滑桿和「任期時間軸」，也收編了網友做的角色外掛。
  - 前端程式碼裡沒有 MediaRecorder，所以沒有匯出影片。
  - 自由時報標題「11萬人讚」。
- **臺北施政島（#4）**
  - 內容跟北海岸政績島最像：任期政績，每項附來源，並標示已完成／進行中／規劃中。
  - 曾捲入抄襲 HEART 的爭議（2026-10-29 多家媒體報導），留言區停在 10/29。
- **陳慧文政績島（#5）**
  - 唯一的議員版本：議員政績加上巡邏角色。
  - 目前下線。
- **今日群島（#6）**
  - 每天 23:08 UTC 由 AI 自動更新議題資料，技術上已經證明「排程 AI 改資料再重新部署」這條路走得通。

## 趨勢（subagent 的推論已標明）

1. 10/22–10/31 一週內在 GitHub 大量出現，背後有一份流傳的 prompt 模板。（推論）「3D 島」形式本身已經不是差異點。
2. 作品分三條路線：官方陣營、支持者或中立網友、諷刺。
3. 功能趨同：時段切換、「某某人的一天」、角色收集、集章、測驗、分享卡、附來源。**在檢查範圍內，沒有任何作品能匯出短影片。**
4. （推論）「3D 島＋真實的每日行程＋回顧＋匯出短影片」這個組合在查找範圍內沒人做；最接近的作品各缺一塊。
5. （推論）選後多數競選島會停止更新。主打選後持續更新，就能避開正面競爭。
6. 風險：「恐怖島」這種格式可能被反過來用，盤點議員的爭議。
