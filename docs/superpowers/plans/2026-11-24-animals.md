# 貓狗（島上隨機走動）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 兩隻貓、兩隻狗，用民眾同一套圓角粉彩風格做造型，先在圖庫展示，再在島上沿路網隨機走、偶爾坐下。

**Architecture:** 新資料夾 `src/scene/animals/`：`stroll.ts` 是純邏輯的「走／停」排程器（可測）、`dog.ts`／`cat.ts` 各回傳 `{ object, update(t, pose) }`、`index.ts` 匯出 `ANIMAL_TYPES`。島上每隻動物 = 一個 `roadWalker`（既有，`src/scene/traffic.ts`）＋一個 stroll；停頓時不推進 walker。圖庫把動物放在民眾區兩側原地動。

**Tech Stack:** three.js 0.160（`RoundedBoxGeometry`、`CapsuleGeometry`）、TypeScript、vitest。

**Spec:** `docs/superpowers/specs/2026-11-24-animals-design.md`

## Global Constraints

- 造型只用幾何體，不用貼圖；材質用 `figure.ts` 的 `soft()`（平滑著色），零件用 `rbox`／`capsule`。
- 各貓狗原點在腳底中心、y 朝上、**面向 +x**（和競選車同慣例，`rotation.y = heading` 直接可用）。
- scale 1 時：狗高約 0.42 長約 0.5；貓高約 0.3 長約 0.42。島上 ×2。
- 毛色：狗「柴犬黃＋米白」「黑＋棕眉」；貓「橘＋白肚」「黑白（黑身白吻白腳）」。同種兩隻各一組。
- 速度：貓 1.0–1.3、狗 1.6–2.0（競選車 2.2）。停頓：走 6–14 秒、停 2–4 秒，由 rng 決定。
- 停頓姿勢：狗 `sit`；貓 `sit` 或 `lie` 二選一（rng）。
- 註解用繁體中文，跟專案其他檔案一致。

## Review Focus

- `dt` 為 0 或負值（分頁切回來、clock 重設）：stroll 不能跳相位或產生 NaN（Task 1 測）。
- 一次很大的 `dt`（例如 30 秒）：stroll 只能前進到下一段狀態，不能一口氣跨好幾段又把剩餘時間亂算（Task 1 測）。
- 同一隻動物連續呼叫 `update` 時姿勢從 `walk` 切到 `sit`：腿、尾的旋轉要重設，不能留著走路的殘值（Task 2 用「切回 walk 後 legs rotation 在走路範圍內」的 smoke test 鎖住）。
- 路網 walker 的 `heading` 是 `-atan2(dz, dx)`，右側偏移算錯會讓動物走進路中央或掉出路肩（Task 4 寫單元測試鎖公式）。
- 圖庫 `&animals=1` 近看時標籤不能跟民眾標籤疊在一起（Task 3 用 label 放頭頂上方 y=0.9 處）。
