# 背景改成馬蹄形出海口（2026-11-27，短設計）

## 意圖

現在整座島坐在火山口湖裡，四周整圈都是山，只在夕陽方向開了一個窄窄的低窪（`src/scene/crater.ts` 的 `gapFactor`）。這個做法本來是參考政策島的（見檔頭註解），跟北海岸真實的地形不一樣。

北海岸的實際地形是：
- 山只在陸地那一側：東邊是大屯山系，南邊是觀音山和林口台地。
- 北邊和西邊是打開的台灣海峽。
- 淡水河從東南邊的關渡流進來，從西北邊出海。

改成馬蹄形，可以讓地理是真的，畫出在地人認得的「淡水夕照」，也順便拿掉「被山整圈圍住」這個政策島的元素。（使用者同意，2026-11-27）

## 做法

- **海側開口**：把現在的窄低窪改成大開口。開口中心沿用現在的夕陽方向（淡江大橋中點 → 議會，`main.ts` 已經算好），開口寬度約 100°–140°，具體由實作者看畫面決定。開口那一側的地形要降到海平面以下，讓人從島上望向外海時看得到海平線。
- **河谷缺口**：在關渡方向切一道窄缺口，寬度大約一格。方向是從場景中心指向關渡大橋中點（格 `-1,-2` 和 `-1,-1`）。淡水河從這裡進入島中間的河道。缺口旁標一個「→ 台北」的小標籤，樣式沿用現有的地名標籤。
- **陸側山稜**：其餘部分維持現在的山稜和樹。
- **議會島**：位置不動，剛好浮在夕陽方向的外海。
- **鏡頭範圍**：沿用現在的橢圓邊界（`lakeLocal` 的半徑限制）。開口那一側雖然沒有山，鏡頭一樣不能超出這個邊界。
- **霧與海**：調整霧的距離，讓海平線柔和地消失，不能露出海面圓盤的邊緣。

## 不做的

- 不在山上標「大屯山系」「觀音山」這類名稱。島上的觀音山和大屯山已經有地名標籤了。
- 不在水面上寫河名、海名，不改區名標籤的樣式。這些都屬於使用者判斷為「過度設計」的視覺點子。

## 留給實作的人決定

開口寬度、山稜收尾的形狀、霧的參數，以及河谷缺口的深度。

## 測試

- 補 `crater` 的單元測試（現有的 `tests/crater.test.ts`）：
  - 開口方向的地形高度要低於海平面
  - 河谷缺口方向要比兩側低
  - 其他方向的高度不變
- 用 `?cam=sunset`、`?cam=top` 和預設環繞鏡頭各截一張圖，人工確認。

## 順序

時間軸的「匯出影片」要等這項完成之後再做，影片的構圖會用到它。其他時間軸功能可以同時進行。
