# 分組物件與政績側欄（2026-11-24）

推翻 [專案架構設計](2026-11-24-project-architecture-design.md) 的兩條：
「每一篇貼文在島上有一個對應的建築」改為**每組一個物件**；「互動查詢」從非目標改為**點物件看政績**。
搜尋、持續更新、CMS 仍是非目標。

## 分組

- 組 = **島 × 元素**（元素來自 `scripts/lib/classify.mjs` → `data/elements.json`）。879 篇 → 56 組：
  淡水 13、八里 13、三芝 10、石門 10、議會島 10。
- 物件大小隨篇數放大（對數、有上限）。
- 落格：每組放在「它的貼文最多落在的那一格」（`data/cells.json`）；同格最多 4 組，滿了改放次多的格。
  議會島照 `councilTiles` 三格的歸屬；議會大樓固定在主格中心。
- `sign` 在側欄叫「其他政績」。
- 競選車、渡輪、民眾、山、樹、橋都是裝飾，不能點。

## 流程

```
進站：自動環繞
 ├ hover 物件 → 浮起、游標旁提示「淡水 · 路口改善 118 篇」
 └ click 物件 → 鏡頭飛到物件斜上方、停止環繞；其他物件變淡；側欄滑出
      ├ 點一篇 → 側欄內展開：縮圖（目前 placeholder）、摘要、日期、「閱讀原文 ↗」（新分頁）
      ├ 點另一個物件 → 側欄換內容、鏡頭飛過去
      └ ✕ / Esc / 點空白處 → 側欄收起、鏡頭回原位
```

## 側欄

- 標題：「區 · 類型」、篇數、年份範圍、議題比例條。
- 議題篩選 4 類：交通、民生、教育與校園（校園＋教育）、其他（無議題＋長照）；只篩清單，不動島。
- 依年份分段、新的在上；最新一年展開，其餘收合。
- 每篇：日期、標題、內文前段摘錄、縮圖（placeholder）、原文連結。
- 手機（寬 < 720px）：改成底部面板，佔畫面下半。

## 網址

`?g=<island>-<element>` 打開某一組；`&p=<postId>` 展開某一篇。用 `history.replaceState`，不留歷史紀錄。

## 資料

`scripts/build-groups.mjs`：`data/elements.json` + `data/cells.json` + `temp/posts-geo.json`（標題、日期、連結）
+ `temp/withyuen-api-*/posts.json`（內文摘錄）→ `data/groups.json`。分組與落格邏輯在 `scripts/lib/groups.mjs`，有測試。

## 縮圖

暫時一律 placeholder（議題色塊＋元素名）。之後決定引用原站圖片或下載進專案。
