# 格內場景化佈局（2026-11-24）

參考政策島（puma.taipei/heart-island）：一格是一幅小舞台，不是一堆物件。先在議會島兩格試，成立再推到地方島。

## 政策島看起來合理的原因（已觀察）

- 一格一個場景：一棟主建築偏離格心、兩三個中型道具靠著它、小東西沿路邊散。
- 地面先分區（廣場鋪面、草地、水池），格間有窄步道與水道隔開。
- 一條主幹道貫穿，建築面向它，整島有共同的「正面」。
- 大東西少、小東西多；樹只在角落與邊緣，格中央留給主建築與廣場。
- 人成群、有事做，不均勻灑。

## 規則（議會島先試）

1. **主物件**：該格篇數最多的那組；議會島主格固定是議會大樓。放在格心，面向主街。放大 1.3 倍。
2. **主街**：從「面向主島中心的那扇門」通到格心廣場的直路（寬 0.9）；格心是圓形廣場（鋪面色，半徑 = 主物件保留圓）。議會島主格的主街門就是碼頭那扇門。
3. **配角**：其餘各組沿主街兩側交錯排（離街心線 1.4，從廣場邊往門排、間距依佔地），面向主街；排不下的繞廣場後側（背對主街那半圈）面向格心。告示牌組算配角，排最後。
4. **縮放**：主物件 1.3；配角沿用篇數對數縮放但上限 1.3。
5. **樹**：只放環道外側與沒有物件的角落（議會島沒樹，這條先不動）。
6. **人**：之後改成成群站在相關物件旁；議會島沒有分配到人，先不動。
7. **地方島**：之後套同一套，再加「漁港靠海、學校貼主街、路口貼環道」三條語意。

## 實作

- `src/scene/place.ts`：`layoutScene(items, { R, streetDir, reserve, seed })` 純幾何，回傳每組位置、朝向、是否主物件。
- `src/scene/streets.ts`：`buildStreet(tile, R, gate, plazaR)` 畫廣場與主街。
- `src/scene/groups.ts`：`placeGroups` 在 `opts.scene` 為真時改走 `layoutScene`；`main.ts` 對 `council*` 兩格開啟。
- 測試：主物件在格心；配角交錯在主街兩側、離街心線 1.4、全在可用區內、間距照佔地；朝向：配角面向主街。
