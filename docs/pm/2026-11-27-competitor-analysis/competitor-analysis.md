# 「議員在哪裡」競品分析（2026-11-27）

> 方法：phuryn/pm-skills `competitor-analysis`（@ 9af7bfd），借 coreyhaines31 `competitor-profiling`（@ 2bf95ed）的原則：
> 每一點分成 **【觀察】**（有來源）、**【推論】**（我的解讀）、**【意涵】**（對本專案的選項）。
> SaaS 範本裡的募資、市佔、定價欄位，對政治人物的溝通工具多半不適用，標「不適用」；查不到的標「無資料」。

## 0. 被分析的設計（截至今天的討論）

北海岸政績島上新增一個議員角色：
- **現在模式**：今天去過的地點插旗，角色沿路網開到下一站，附一句「在做什麼」，有直播就顯示縮圖＋外連。
- **回顧模式**：選一天「播放這一天」（角色依序重開一遍行程，鏡頭跟拍）；週、月、各區累計站數。
- **後台**：Supabase、Google 登入白名單（議員＋一兩位同仁）；手機現場一鍵記錄（GPS 只用來推薦最近的島上地點），也支援事後補登。
- **目的**（使用者原話）：議員在社群分享，讓大家感受到她很認真；比傳統文字和照片更吸引眼球；更容易做歷史回顧。

## 1. 市場範圍

- **這是什麼市場**：不是一般的商業市場，而是「民意代表的勤政溝通」。只有一位客戶（鄭宇恩議員／辦公室），受眾是北海岸四區（淡水、八里、三芝、石門）的選民與支持者。市場規模、成長率：不適用。
- **要做的事（JTBD）**：讓人感受到議員有在跑基層、而且看得到累積，不是只在選前出現。
- **成功關鍵**：
  1. 議員願意持續記錄，記錄成本夠低
  2. 輸出的東西在社群上能被看到，也就是演算法會推
  3. 讓人相信，不像純公關
  4. 累積的歷史回頭看得到
- **競爭強度**：對手不是同類產品，而是議員本來就在用的發文習慣。換句話說，真正的對手是「維持現狀」。

## 3. 逐家分析

### 3.1 FB／IG（含 Threads）：現狀，也是最大的對手

**概況**
- 【觀察】Meta 透明度資料：美國動態消息的觀看次數超過 98% 來自**不含連結**的貼文。（Social Media Examiner／TechCrunch 轉述，2025-12）
- 【觀察】Meta 從 2025-12-16 起測試「粉專每月只能發 2 則含外部連結的貼文」，留言裡的連結也算在內；超過的話連結不能點。Meta One 付費方案（約 2026-09-15 上線）可以提高額度：Essential 仍是 2 則、Advanced 8 則、Max 無上限。（TechCrunch 2025-12-17；Press Gazette；netsourceinc、duoplus.nz 2026）
- 【觀察】有來源說紐西蘭、澳洲已經實施。Meta 表示這個限制「可能不適用所有粉專」。**台灣是否已經實施：無資料。**（unwire.hk 2026-08-13：香港未獲官方確認）
- 【觀察】連到 Meta 自家服務（IG、FB 活動、社團）的連結不受限制。
- 【觀察】已有報導指出 Threads 成為台灣公共輿論設定議程的重要平台，提到的例子是其他議員，跟鄭宇恩無關。（王宏恩，搜尋結果）

**強項**
- 受眾都在這裡，發文零學習成本，照片、影片、直播都是原生功能。
- 限時動態、打卡地點本來就能表達「我現在在哪」。

**弱點**
- 【推論】動態消息會把舊內容沖掉，「這四年在八里跑了幾次」在 FB 上幾乎看不到。
- 【推論】一則一則的貼文沒有累積起來的總覽畫面，看不出「整體有多認真」。

**對本專案的威脅**
- 【意涵】**「發一個島的連結」這種分享方式，正好撞上 Meta 壓低連結觸及的方向。**如果台灣也實施每月 2 則的限制，議員每個月只能分享兩次島，跟「每天記錄」的節奏完全對不上。
- 【意涵】議員不會為了島放棄 FB。島要搶的不是發文平台的位置，而是「FB 做不到的累積與回顧」，再把成果**做成 FB 會推的影片格式**送回去。

### 3.2 withyuen.com 問政紀錄：議員自己的回顧管道

- 【觀察】本專案的資料快照：879 篇，2022–2026，每年約 200–250 篇，平均每週 4–5 篇。每篇有日期、標題、主題分類（教育與校園、交通…），而且已經由本專案的管線地理編碼、落到島上的格子。（`data/groups.json`）
- **強項**：內容完整、可搜尋、是正式紀錄，也有利於 SEO。
- **弱點**：【推論】它是文章列表，沒有空間感和時間感，一般人不會從頭翻到尾。
- **對本專案的意涵**：
  - 【意涵】它比較像**資料來源**，不太算競爭對手。879 篇都已經帶有日期和格子，所以回顧模式**上線第一天就能有四年的歷史**，不必從零開始累積。這是 Relive、Polarsteps 和 HEART 都沒有的優勢。
  - 【意涵】每一站可以連回對應的文章，讓「去了哪」和「做了什麼」互相佐證。

### 3.3 沈伯洋 HEART 政策島：同類型的標竿

**概況**
- 【觀察】2026-10-22 上線，是台北市長競選官網的一部分。14 個政策主題、94 個細項，做成一座台北形狀的 3D 微縮島，有 20 條「協作線」，藏有 Q 版沈伯洋人偶彩蛋，可以搜尋，每項政策都連回官網。（自由時報、遠見、NOWnews，2026-10）
- 【觀察】上線後出現諷刺蔣萬安的「二創政策島」，也有人仿作其他縣市的版本。（同上）

**強項**
- 證明了台灣受眾願意逛 3D 政治網站，而且會自發二創、傳播。
- 有競選團隊的資源，也有媒體曝光。

**弱點**
- 【推論】內容是**承諾**（未來），上線後就靜止不動，沒有回訪的理由。
- 【推論】這種形式已經被大量模仿，新鮮感正在下降。

**對本專案的威脅與機會**
- 【意涵】本專案的架構文件已經把「做成政策島的複製品」列為反目標，現有的差異是「真實輪廓、真實的橋、資料是已發生的事」。**加上「議員在哪裡」之後，差異會更大：HEART 是一座靜態的島，這座島每天都會動。**
- 【意涵】風險是被看成「又一個政策島」。對外說法建議強調「**會動的、記錄中的**」，避開「政策島」這個詞。

### 3.4 Relive：「路線變影片」的標竿

- 【觀察】免費版每個活動可以做一支 3D 影片，橫式、直式都有，可以分享到 FB、IG、X。Relive Plus 可以加音樂、更多照片、重複編輯；美國 App Store 價格標示為 US$6.99 和 US$38.99，但沒寫哪個是月費、哪個是年費。（App Store 頁面，可能是舊資料）
- 【觀察】有第三方網站說它 2025 年約有 2,200 萬使用者，來源是二手資料。Strava 在 2019 年以違反 API 條款為由切斷跟 Relive 的串接，2023 年自己推出 Flyover，只給付費會員用。（Cycling Weekly、road.cc、TechCrunch 2023-11-15）
- **強項**：【推論】核心洞察是**分享的單位是影片，不是連結**。影片直接進社群，平台不會壓低觸及。
- **弱點**：它的價值綁在 GPS 軌跡上，Strava 一斷串接就很受傷。
- **對本專案的意涵**：
  - 【意涵】**這是最該借的一點：「播放這一天」除了在網頁上放，還要能匯出成 10–20 秒的直式影片**，讓議員直接發成 Reels、限動或 Threads。影片角落放島的網址或 QR code，想深入看的人自己會來。
  - 【意涵】Strava 自己做了 Flyover，代表這個功能有人買單，大平台才會抄。

### 3.5 Polarsteps：「足跡變回顧」的標竿

- 【觀察】免費版有：旅行統計、刮刮地圖、產生 Trip Reels（2025 夏季版加入，可分享）、行程規劃、追蹤親友的旅程。Plus 版每月 €8.99、每年 €29.99，多了 3D 地圖、更多地圖樣式、步數統計。也有付費的實體 Travel Book。（polarsteps.com/plus、support.polarsteps.com）
- **強項**：【推論】把「累積」本身做成產品：統計數字、刮刮地圖、年度回顧、實體書。親友可以「追蹤」一段旅程。
- **弱點**：只適合有起點和終點的旅程，不適合日常。
- **對本專案的意涵**：
  - 【意涵】統計和刮刮地圖對應到「本月 61 站」、「八里今年 23 次」，以及**島上去過的格子慢慢點亮**，這最能讓人直覺感受到累積。
  - 【意涵】Travel Book 對應到**任期回顧**。2030 年任期結束時，一份「四年走過北海岸」的回顧，本身就是很好的素材。這是長期的價值，不急著做。
  - 【意涵】Polarsteps 也把 Trip Reels 放進免費版，再次證明短影片是分享的主要單位。

## 4. 差異化機會

1. **把地點和政績串起來**：沒有任何競品能把「她去了哪」和「她在那裡做了什麼」放在同一個畫面上。島上已經有 56 個政績物件，再加上行程，就能從地點直接看到成果。
2. **第一天就有四年的歷史**：879 篇文章已經有日期和格子，可以回填進回顧模式。新產品最難的「空白期」可以直接跳過。
3. **用影片分享，不用連結**：同時避開 Meta 的連結限制，又符合 Relive、Polarsteps 都驗證過的分享方式。
4. **每天都會變**：HEART 一上線就定型；這座島會隨著議員每天的行程更新，訪客有理由一再回來。
5. **選區地理很具體**：北海岸四區是真實輪廓，在地人會去找「我家那一格」。這是全市尺度的 HEART 很難做到的親近感。

## 5. 主要風險（照嚴重程度排）

| 風險 | 說明 | 緩解 |
|---|---|---|
| **議員不持續記錄** | 每次記錄都比發 FB 多一個動作。停更的島比沒有島更糟，等於在公開說她最近沒在動 | 現場記錄要在 10 秒內完成；同仁可以事後補登；回填歷史文章；**不顯示「最後更新：N 天前」** |
| **社群觸及不到** | 只發連結會被壓低觸及，也可能被每月 2 則的限制卡住（台灣是否實施：無資料） | 匯出直式影片；連結改放 IG 個人簡介、Threads、LINE |
| **被認為是公關** | 自己報的行程，沒有第三方佐證 | 每一站連到公開貼文或照片；統計數字照實呈現；第一期不做排名之類的比較 |
| **被看成又一個政策島** | 形式被大量模仿，新鮮感下降 | 對外強調「會動、記錄中」；跟 HEART 的視覺語言已經刻意拉開 |
| **人身安全** | 公開即時位置 | 位置只到島上的格子；只記公開行程；議員可以選擇事後才登錄 |

## 6. 競爭定位建議

**定位一句話（草案）**：
> 「不是政見，是足跡。」北海岸政績島把宇恩每天跑過的地方和做過的事放在同一座島上，一天的行程可以變成 15 秒影片，四年的累積隨時回頭看。

**要強調的差異**：會動、累積、地點加政績、影片分享。

**避開**：
- 不跟 FB 搶「發文平台」的位置，島是 FB 的素材工廠和資料庫。
- 不跟 HEART 比政見。
- 不追求精確的即時定位。

**對原設計的建議修改**：
1. **把「匯出今天的直式影片」列為核心功能**。技術上可以在瀏覽器裡錄 canvas 做出來，至少排進第二期，最好跟回顧模式一起做。
2. **第一期就回填 879 篇文章**當成歷史站點。這些文章只代表「有發文」，不一定代表「人在現場」，要用不同圖示區分。
3. **記錄流程的目標是 10 秒內完成**，上線後先追蹤「每週記錄天數」。這是最早能看出產品會不會死掉的指標。
4. **不要假設一定能靠 FB 連結導流**。上線前先用議員的粉專測試，看看是否已經受到每月 2 則的限制。

**12–18 個月要追蹤的**：
- Meta 的連結政策在台灣的實施狀況
- 其他政治人物是否推出類似的「行程地圖」（目前沒查到同類產品，但沒查到不等於不存在）
- Threads 在地方議員之間的使用率
- 2030 年任期回顧的時機
